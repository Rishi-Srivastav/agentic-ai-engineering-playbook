# RAG Review Checklist

- [ ] Source ownership and freshness defined
- [ ] Parsing preserves important structure
- [ ] Chunking strategy justified
- [ ] Metadata includes ACL/version/source
- [ ] Retrieval top-K tuned on evaluation data
- [ ] Hybrid retrieval considered for exact terms
- [ ] Reranking measured before adoption
- [ ] Context budget enforced
- [ ] Citations map to exact sources
- [ ] Retrieval and generation evaluated separately
- [ ] Out-of-domain behavior tested
- [ ] Stale-index scenario tested
