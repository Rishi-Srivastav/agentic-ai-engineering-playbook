# MCP Server Review Checklist

- [ ] Tool names are specific and action-oriented
- [ ] JSON schemas are explicit
- [ ] Unknown/invalid arguments are rejected
- [ ] Authentication is enforced
- [ ] Authorization is server-side
- [ ] Tenant/user context is server-derived
- [ ] Side effects are classified
- [ ] Idempotency is defined
- [ ] Timeouts are bounded
- [ ] Errors use safe categories
- [ ] Sensitive arguments are not logged
- [ ] Metrics and traces exist
- [ ] Tool output has size limits
- [ ] Destructive operations have approval/confirmation where required
