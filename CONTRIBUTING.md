# Contributing

Keep this repository practical and production-focused.

## Preferred format for a new pattern

1. Problem
2. When to use it
3. When not to use it
4. Architecture / flow
5. Failure modes
6. Security considerations
7. Observability
8. Evaluation strategy
9. Trade-offs
10. Minimal implementation example

Avoid framework-specific advice unless the framework detail materially changes the design.
