# RAG Evaluation

Separate **retrieval quality** from **generation quality**.

### Retrieval metrics

- Recall@K
- Precision@K
- MRR
- nDCG
- Context relevance
- Context coverage

### Generation metrics

- Faithfulness / groundedness
- Answer relevance
- Citation correctness
- Citation completeness
- Refusal correctness

Maintain a golden set containing easy, ambiguous, adversarial, out-of-domain, and freshness-sensitive queries.
